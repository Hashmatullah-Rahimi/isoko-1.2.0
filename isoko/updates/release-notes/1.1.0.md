# Isoko 1.1.0

**Date:** 2026-10-19
**Type:** Store update (new build) — first public version will include this.

## What's new
- **Languages:** English, Français, Ikinyarwanda. Globe button (🌐) on the welcome and log-in screens, and Profile → Language. The first time, the app follows the phone's language.
- **Messages:** live in-app chat between a buyer/renter and the owner, one chat per listing.
  - "Message" button in the new "Contact the owner" card on each listing.
  - "Message" button on each buy/rent request (works for owners too).
  - Inbox: chat icon at the top of Home, or Profile → Messages. Red badge = unread.
  - Quick first messages: "Is it still available?", "Can I come and see it?", "Is the price negotiable?"
- **WhatsApp:** owners choose if buyers/renters may contact them on WhatsApp (on sign-up, and later in Edit profile). The number is only given to logged-in Buyer & Renter accounts.
