# 4. Design system

## Colours (`src/theme/colors.ts`)

| Name | Colour | Used for |
|---|---|---|
| Brand / Houses | `#0B6E5C` emerald | Main buttons, everything about houses |
| Brand light | `#14A386` | Gradients, highlights |
| Night | `#062F2B` | Intro, welcome and login backgrounds |
| Cars | `#2848D6` royal blue | Everything about cars |
| Gold | `#F4B740` | Accent: the logo's dot, "+ Post" button, owner badge |
| Ink | `#0D1B1E` | Headings |
| Background | `#F5F6F3` | Screen background (soft warm white) |

Houses always appear in green and cars always in blue, so people instantly know which section they're in — they never mix.

## Font

**Plus Jakarta Sans** (free, Google Fonts) in five weights. Text styles live in `src/theme/typography.ts` and are used with `<AppText variant="h1">`.

## Logo

`assets/brand/isoko-mark.svg` — a roof (houses) over a road (cars), forming the letter "i" with a gold dot.
- In the app it's drawn by `src/components/brand/Logo.tsx`, which can animate: the roof draws itself, the road fades in, the dot pops.
- App icons and the splash are generated by `tools/generate-icons.js` → `npm run icons`.

## Animations (React Native Reanimated)

| Where | Animation |
|---|---|
| Intro | Roof draws, road appears, gold dot springs in, letters of "Isoko" drop in one by one |
| Welcome, login, sign-up | Coloured glows float slowly in the background; cards and fields slide in one after another; form sheet slides up |
| Login error | The form shakes |
| Every button / card | Shrinks slightly when pressed, springs back, light vibration |
| Tab bar | Floating, blurred; active tab gets a highlight pill and the icon bounces |
| Houses / Cars | Coloured header shrinks and fades as you scroll; Buy/Rent/Accessories pill slides |
| Lists | Cards spring in one after another; shimmer placeholders while loading |
| Listing page | Photos move slower than the page (parallax) and zoom when pulled; top bar fades in; photo dots stretch |
| Heart | "Pop" animation when saving |
| Post wizard | Progress bar springs forward; steps slide sideways; photos zoom in/out |
| Empty lists & success | Illustrations float gently; success tick zooms in |

## Reusable pieces

`src/components/ui`: `AppText`, `Button` (primary, gold, outline, ghost, danger…), `Input`, `Chip`, `SegmentedControl`, `IconButton`, `Avatar`, `Badge`.
Use these when you build new screens so everything keeps looking the same.
